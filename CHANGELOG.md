# Change Log

All notable changes to the "cf-logs-highlighting" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.0.2] - 2026-08-19

- Added robust highlighting for CF envelopes, log levels, logger names, and
  messages containing escaped JSON.
- Restored the metadata scopes used by compatible themes to hide unnecessary
  request and tracing fields.
- Avoided modifying global VS Code color settings.
